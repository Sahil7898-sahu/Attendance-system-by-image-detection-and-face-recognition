# SHIKSHA2025

## Project Overview
Flask-based biometric attendance system using face recognition and MongoDB.

## Features
- Teacher & principal login
- Teacher registration
- Student registration with face image uploads
- Face recognition from uploaded image
- Attendance logging in MongoDB
- Dashboard to view attendance logs

## Requirements
- Python 3.x
- MongoDB running locally
- Python packages:
  - `flask`
  - `pymongo`
  - `werkzeug`
  - `face_recognition`
  - `opencv-python`
  - `numpy`
